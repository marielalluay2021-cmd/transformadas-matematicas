Distribución Gamma (Gi)

Generador de Variables Aleatorias

Concepto

La distribución Gamma se utiliza para modelar tiempos de espera asociados a la ocurrencia de varios eventos aleatorios.

En este método se generan variables aleatorias Gamma a partir de números aleatorios uniformes.

Parámetros

  • 1/λ: valor esperado.
  • k: parámetro de forma.
  • rj: números aleatorios entre 0 y 1.

Fórmula

Gi = − 1 kλ ln ( ∏ k j=1 (1 − rj) )
