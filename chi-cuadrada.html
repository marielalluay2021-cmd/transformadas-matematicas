Distribución Chi-cuadrada χ²

Generador de Variables Aleatorias

Concepto

La distribución Chi-cuadrada se utiliza para generar variables aleatorias continuas a partir de variables normales estándar.

Su comportamiento depende de los grados de libertad de la distribución.

Para generar una variable Chi-cuadrada se elevan al cuadrado varias variables normales estándar independientes y posteriormente se suman.

Datos de entrada

Distribución Chi-cuadrada (χ²i)

La variable Chi-cuadrada se obtiene mediante la suma de los cuadrados de variables normales estándar independientes:

χi2 = ∑ n j=1 Zj2

Notas / Parámetros:

Zj: Variables aleatorias independientes con distribución Normal estándar N(0,1).

n: Grados de libertad de la distribución Chi-cuadrada.
