Distribución Chi-cuadrada χ²

Generador de Variables Aleatorias

Concepto

La distribución Chi-cuadrada se utiliza para generar variables aleatorias continuas a partir de variables normales estándar. Su comportamiento depende de los grados de libertad establecidos.

Para generar una variable Chi-cuadrada se elevan al cuadrado varias variables normales estándar y posteriormente se suman.

Datos de entrada

Método de generación

La variable Chi-cuadrada se obtiene mediante la suma de los cuadrados de variables normales estándar:

χ² = Z₁² + Z₂² + ... + Zₙ²

Donde Z representa una variable normal estándar y n corresponde a los grados de libertad.
