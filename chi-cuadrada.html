Distribución Chi-cuadrada χ²

Generador de Variables Aleatorias

01. Concepto

La distribución Chi-cuadrada se utiliza para generar variables aleatorias continuas a partir de números aleatorios con distribución normal estándar.

03. Método de generación

Para generar cada variable Chi-cuadrada, primero se obtienen números aleatorios con distribución normal estándar. Luego se elevan al cuadrado y se suman de acuerdo con los grados de libertad seleccionados.

χi2 = ∑j=1n Zj2

Zj = número aleatorio con distribución normal estándar
n = grados de libertad
