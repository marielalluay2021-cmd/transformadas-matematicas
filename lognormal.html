Distribución Lognormal (LNi)

Generador de Variables Aleatorias

Concepto

La distribución Lognormal se utiliza para modelar variables aleatorias que únicamente pueden tomar valores positivos.

En este método se genera una variable normal y posteriormente se aplica la función exponencial para obtener la variable Lognormal.

Parámetros

  • μ: valor esperado (media).
  • σ²: varianza.
  • ri: números aleatorios independientes entre 0 y 1.
  • Σri: suma de 12 números aleatorios uniformes U(0,1).
  • Ni: variable normal utilizada para generar la variable Lognormal.
  • e: base de los logaritmos naturales.

Fórmula

LNi = e Ni

Donde:

Ni = ( Σ i=112 ri − 6 ) · √ ln ( 1 + σ² μ² ) + ln ( μ² √(μ² + σ²) )
