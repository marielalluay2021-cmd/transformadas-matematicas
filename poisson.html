Distribución Poisson (Pi)

Generador de Variables Aleatorias

Concepto

La distribución de Poisson permite generar variables aleatorias que representan el número de ocurrencias de un evento durante un intervalo determinado.

Parámetros

  • λ: Media de la distribución de Poisson.
  • N: Contador del número de eventos.
  • T: Producto acumulado de los números aleatorios.
  • ri: Número aleatorio entre 0 y 1.

Algoritmo de generación

Inicialización: Hacer N = 0, T = 1 y generar un aleatorio ri.


Paso 1: Calcular:

T' = (T)(ri)

Paso 2: Si:

T' ≥ e−λ

entonces hacer N = N + 1, T = T', calcular otro ri y regresar al paso 1.


Condición de parada: Si:

T' < e−λ

entonces la variable generada está dada por:

Pi = N

Para generar la siguiente variable de Poisson, regresar a la fase de inicialización: N = 0 y T = 1.
