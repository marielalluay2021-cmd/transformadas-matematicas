Distribución Poisson (Pi)

Concepto

La distribución de Poisson permite modelar el número de eventos que ocurren durante un intervalo determinado, cuando estos eventos ocurren de manera independiente y con una tasa promedio constante.

P(X = x) = (e−λ λx) / x!

Parámetro

λ: representa el número promedio de eventos que se espera que ocurran durante el intervalo considerado.

En el algoritmo se utiliza el límite: e−λ

Por ejemplo, si λ = 12: e−12 ≈ 0.0000061442

Algoritmo de generación

  1. Inicializar: N = 0 y T = 1.
  2. Generar un número aleatorio ri entre 0 y 1.
  3. Calcular: T' = T × ri .
  4. Si: T' ≥ e−λ , entonces: N = N + 1 y T = T'.
  5. Generar un nuevo ri y repetir.
  6. Si: T' < e−λ , se detiene el proceso.
  7. Finalmente: Pi = N .
  8. Para generar el siguiente Pi, se reinicia: N = 0 y T = 1.
