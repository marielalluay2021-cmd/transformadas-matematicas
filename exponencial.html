Distribución Exponencial

Generador de Variables Aleatorias · Método de la Transformada Inversa

Concepto

La distribución exponencial se utiliza para modelar tiempos de espera o intervalos entre eventos que ocurren de manera aleatoria.

En este método se utiliza un número aleatorio ri entre 0 y 1 para generar una variable aleatoria exponencial.

Datos de entrada

Distribución Exponencial (Ei)

La variable aleatoria exponencial se obtiene mediante el método de la transformada inversa.

Ei = − ( 1⁄λ ) × ln(1 − ri)

Donde:

ri: número aleatorio entre 0 y 1.

λ: tasa de la distribución exponencial.

1/λ: media de la distribución exponencial.
