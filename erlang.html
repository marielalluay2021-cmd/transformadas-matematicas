01. Concepto

La distribución Erlang es una distribución continua utilizada para modelar tiempos de espera que pueden considerarse como la suma de varias variables aleatorias exponenciales.

03. Método de generación

Para cada variable Erlang se generan k números aleatorios uniformes entre 0 y 1. Luego se aplica la fórmula correspondiente.

FÓRMULA DE ERLANG
ERi = − 1 kλ ln ∏ k j = 1 (1 − rj)
Donde: λ = valor esperado   |   k = parámetro de forma   |   rj = número aleatorio
