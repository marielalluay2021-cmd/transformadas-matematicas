Distribución Erlang

Generador de Variables Aleatorias

01. Concepto

La distribución Erlang es una distribución continua utilizada para representar tiempos de espera y procesos que están formados por varias etapas.

En este método se utilizan números aleatorios uniformes entre 0 y 1 para generar las variables aleatorias Erlang.

03. Método de generación

Para generar cada variable Erlang se utilizan k números aleatorios entre 0 y 1. Los números generados no se repiten.

ERi = − 1 kλ ln ∏ k j=1 (1 − rj)

Donde:

ERi = variable aleatoria Erlang

λ = tasa de ocurrencia

k = parámetro de forma o número de etapas

rj = números aleatorios entre 0 y 1 sin repetirse

Importante: los valores de r se generan desde 0.000001 hasta 0.999999.

Cada número aleatorio utilizado en la tabla es diferente, evitando repeticiones.
