03. Método de generación

Para generar cada variable Erlang se utilizan números aleatorios entre 0 y 1. Luego se aplica la fórmula correspondiente según los valores de λ y k.

ERi = − 1 kλ ln ∏j=1k (1 − rj)

ERi = variable aleatoria Erlang

λ = tasa

k = número de etapas

rj = número aleatorio entre 0 y 1
