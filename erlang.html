¿Cómo funciona?

La distribución Erlang permite representar tiempos de espera que se producen mediante varias etapas.

Para generar cada variable se utilizan números aleatorios r entre 0 y 1.

Los números aleatorios generados en esta página no se repiten dentro de una misma tabla.

Nota: Los valores aleatorios se generan nuevamente cada vez que se presiona el botón "Generar variables".
