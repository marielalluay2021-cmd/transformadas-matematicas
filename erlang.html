03. Método de generación

Para generar cada variable Erlang se utilizan números aleatorios entre 0 y 1. Estos valores se multiplican mediante la fórmula de Erlang de acuerdo con la tasa y el número de etapas.

ERi = − 1 / ( kλ ) ln ∏j=1k (1 − rj)

rj = número aleatorio entre 0 y 1
λ = tasa
k = número de etapas
