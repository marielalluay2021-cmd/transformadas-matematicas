Distribución Binomial (Bi)

Generador de Variables Aleatorias

Concepto

La distribución binomial se utiliza para modelar el número de éxitos obtenidos al realizar N ensayos Bernoulli independientes, donde cada ensayo tiene dos resultados posibles: éxito o fracaso.

Cada ensayo Bernoulli toma el valor 1 cuando ocurre un éxito y 0 cuando ocurre un fracaso. La variable binomial se obtiene sumando los resultados de los N ensayos Bernoulli.

Parámetros

  • Bi: variable aleatoria con distribución binomial.
  • BEij: resultado del ensayo Bernoulli j perteneciente a la variable binomial i.
  • N: número de ensayos Bernoulli que se realizan para obtener una variable binomial.
  • p: probabilidad de éxito de cada ensayo Bernoulli.
  • rij: número aleatorio entre 0 y 1 utilizado para generar cada ensayo Bernoulli.

Fórmula

Bi =
∑j=1N BEij
Bi = BEi1 + BEi2 + ... + BEiN

Relación con la distribución Bernoulli

Para obtener cada variable binomial Bi, primero se generan N variables Bernoulli utilizando la misma probabilidad p.

BEij =
0, si rij < 1 − p
1, si rij ≥ 1 − p

Bi = ∑j=1N BEij
